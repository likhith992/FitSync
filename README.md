# Fitness Tracker

A full-fitness tracker application built for improving your fitness journey.

## Goals

- Personalized workout recommendations
- Personalized diet suggestions
- Calorie calculator
- Protein calculator
- Weight management
- Progress tracking

## Tech Stack

Frontend:
- Next.js
- React
- Tailwind CSS

Backend:
- FastAPI

Database:
- SQLite

Version Control:
- Git & GitHub
